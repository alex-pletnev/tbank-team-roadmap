# Роудмап команды

План работы над кейсом Т-Банка с общими задачами, датами, ответственными и заметками.

## Для команды

- Обычная ссылка открывает просмотр.
- Отдельная ссылка редактора разрешает менять задачи и настройки плана.
- «Сохранить для всех» записывает данные в общее хранилище. Другие участники получают изменения при обновлении или автоматически в течение 20 секунд.
- Если план уже изменён другим участником, сохранение остановится. Ваши поля останутся в форме: можно скачать черновик и загрузить версию команды.
- Новые роли с пометкой «предлагаю» пока не являются подтверждёнными договорённостями.

## Устройство

Страница размещается на GitHub Pages. Общий JSON-документ хранится в R2 через небольшой Worker, развёрнутый в Sites. Браузер передаёт ключ редактора только этому сервису. В коде нет действующих ключей доступа. Изменения защищены проверкой версии и условной записью R2.

Начальные данные: `web/seed.json`. Интерфейс: `web/index.html`, `web/style.css`, `web/app.js`. API: `worker/index.js`. `scripts/bundle.mjs` собирает статическую страницу и модуль Worker.

Команды: `npm test`, `npm run build`. GitHub Pages публикует готовый `index.html` из корня ветки `main`. Для новой сборки скопируйте `public/index.html` в корень публикуемого репозитория. Переменные сервиса: `EDIT_KEY_SHA256`, `ALLOWED_ORIGIN`; R2 binding: `BUCKET`.

Ссылка редактора — это право менять план; передавайте её только команде. При необходимости отозвать доступ замените хеш ключа в настройках сервиса.

Публичная публикация требует подтверждения владельца. Даты 2 и 5 ноября пока учитываются как контрольная точка и поздний ориентир, до уточнения официальных требований.
